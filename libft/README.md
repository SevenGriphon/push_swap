## Description
Libft is a library, containing many usefull function from standard C library as well as some custom functions that are not in libc, that could be usefull for future C projects.

## Instructions
To compile the library file use __make__, __make all__ or __make libft.a__.  
To only compile the library with a main file use __make main__. It requires a file named main.c to exist in the directory.

## Resources
For the description of most of the functions see man \<function name\> (without ft_ prefix).

## Library
This library contains functions to manipulate strings (ft_strlen, ft_strncmp, ft_split...), memory (ft_memset, ft_memmove, ft_memcmp, ft_calloc...) and linked lists (ft_lstnew, ft_lstsize, ft_lstiter)
